# 🌡️ Fahrenheit to Celsius Converter

A simple Python program to convert temperature from Fahrenheit to Celsius.

## 📐 Formula Used
`C = (F - 32) * 5/9`

## ⚙️ Features
- ♾️ Runs in infinite loop for continuous conversion
- 🛡️ Error handling - only accepts numbers

python temp.py
